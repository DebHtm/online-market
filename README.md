# Phone Catalog

A React and TypeScript storefront for phones, tablets, and accessories. The catalog includes product details, sorting, pagination, favorites, and a shopping cart.

## Local development

Install dependencies and start the Vite development server with Node.js 20 and npm.

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

Run `npm run build` to create a production build in `dist`, then run `npm run preview` to view it locally. With the development server running, use `npm test` to run the Cypress tests.
